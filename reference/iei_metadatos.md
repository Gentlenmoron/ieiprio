# Metadatos de un analisis

Reune en una lista todo lo que se registro durante el analisis: build
del genoma, release de Ensembl, archivo VCF y su huella, sexo declarado,
parametros de filtrado, pesos, fenotipo usado, bitacora y control de
calidad.

## Usage

``` r
iei_metadatos(x)
```

## Arguments

- x:

  Resultado de cualquier etapa del flujo.

## Value

Una lista con nombres.
