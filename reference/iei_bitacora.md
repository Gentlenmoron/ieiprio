# Ver la bitacora del filtrado

Ver la bitacora del filtrado

## Usage

``` r
iei_bitacora(x)
```

## Arguments

- x:

  Tabla devuelta por
  [`iei_filtrar()`](https://gentlenmoron.github.io/ieiprio/reference/iei_filtrar.md).

## Value

Un tibble con cada paso, las filas que quedaron y las descartadas. Cada
fila es una variante en una muestra.
